# Viewport 操作与快捷键

SimLab 浏览器前端通过顶部命令栏的 **Shortcuts** 入口打开同一份随前端发布的静态指南。该页面不依赖后端，可在 Vite 开发服务器或生产构建中直接访问。

## 鼠标操作

| 操作 | 结果 |
| --- | --- |
| 左键点击物体 | 选中物体并显示高亮；点击空白区域取消选择 |
| 左键拖动空白区域 | 绕当前相机焦点旋转视角 |
| 滚轮或中键拖动 | 拉近或拉远视角 |
| 右键拖动 | 平移相机焦点 |
| 拖动变换手柄 | 沿选定轴移动、旋转或缩放；松开后保持选择 |

## Viewport 快捷键

| 快捷键 | 工具栏 | 功能 |
| --- | --- | --- |
| `W` | ↔ | 移动工具 |
| `E` | ↻ | 旋转工具 |
| `R` | ⤢ | 缩放工具 |
| `F` | ⌗ | 聚焦选中的 link 或物体；未选中时框选整个场景 |
| `C` | ◇ | 显示或隐藏碰撞体与质心调试图层 |
| `0` | ◆ | 等轴测视图 |
| `1` | ▤ | 前视图 |
| `3` | ◧ | 右视图 |
| `7` | ▣ | 顶视图 |

光标位于 `input`、`select` 或 `textarea` 时不会触发 Viewport 快捷键。

## 项目编辑快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/⌘ + Z` | 撤销 |
| `Ctrl/⌘ + Shift + Z` | 重做 |
| `Ctrl + Y` | 重做（Windows / Linux 习惯键位） |
| `Ctrl/⌘ + S` | 保存场景 JSON |
| `Ctrl/⌘ + Shift + S` | 另存场景 JSON |

## 调试与大型场景

碰撞体调试使用橙色表示动态碰撞体、青色表示静态碰撞体，黄色标记表示质心。仿真会话运行或暂停时，运行时位姿与 authoring transform 保持分离。

加入公里级环境后，Viewport 会自动调整相机距离、裁剪面、雾效和网格尺度。看不清或迷失视角时，按 `F` 重新框选；按 `7` 查看道路与水域平面；按 `0` 返回等轴测视图。
