鼠标与选择

  • 左键单击选择 Actor、关节或传感器，选中对象在 ViewPort 高亮。
  • W / E / R切换移动、旋转、缩放工具。
  • Delete删除当前选中的 Actor。
  • F聚焦当前选择对象，并自动适配大型场景裁剪面。

视口相机

  • 旋转按住右键并拖动。
  • 平移按住中键拖动，或 Shift + 右键拖动。
  • 缩放滚动滚轮 / 双指触控板。
  • 标准视图1 前视、3 右视、7 顶视、0 等轴测。

工作区

每个工具都是一个窗口：拖动 Tab 可移动窗口，悬停目标区域出现五向投放提示（居中加入 Tab 堆、四边分裂新区域）；区域之间拖动分割条调整大小；Ctrl+K 打开窗口库；顶栏可切换布局预设。

其他快捷键

  • Ctrl + K打开窗口库（添加窗口）。
  • Ctrl + Z / Ctrl + Shift + Z撤销 / 重做。
  • Ctrl + S / Ctrl + Shift + S保存 / 另存为。
  • C切换碰撞体与质心调试显示。
