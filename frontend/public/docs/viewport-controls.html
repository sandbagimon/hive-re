Viewport 操作与快捷键

这份速查表覆盖场景选择、相机导航、变换工具、视角切换、碰撞体调试以及项目编辑操作。

Viewport 快捷键在光标位于输入框、下拉框或多行文本框时不会触发，避免编辑属性时误操作场景。

鼠标操作

操作结果
左键点击物体选中物体并显示高亮；点击空白区域会取消选择。
左键拖动空白区域绕当前相机焦点旋转视角。
滚轮 / 中键拖动拉近或拉远视角。
右键拖动平移相机焦点。
拖动变换手柄沿选定轴移动、旋转或缩放物体；松开后物体仍保持选中。

Viewport 快捷键

快捷键工具栏功能
W↔切换到移动工具。
E↻切换到旋转工具。
R⤢切换到缩放工具。
F⌗聚焦选中的 link 或物体；未选中时框选整个场景。
C◇显示或隐藏碰撞体与质心调试图层。
0◆等轴测视图。
1▤前视图。
3◧右视图。
7▣顶视图。

项目编辑快捷键

快捷键功能
Ctrl / ⌘ + Z撤销上一步场景编辑。
Ctrl / ⌘ + Shift + Z重做。
Ctrl + Y重做（Windows / Linux 习惯键位）。
Ctrl / ⌘ + S保存场景 JSON。
Ctrl / ⌘ + Shift + S另存场景 JSON。

调试图层

Dynamic

橙色线框表示动态碰撞体。

Static

青色线框表示静态碰撞体。

Center of mass

黄色标记表示物体质心。

仿真状态

仿真会话运行或暂停时，运行时位姿与编辑状态分离，变换手柄不会修改 authoring transform。

大型场景建议

加入公里级场景后，Viewport 会自动调整相机距离、裁剪面、雾效和网格尺度。看不清或迷失视角时，先按 F 重新框选，再用 7 查看道路与水域平面，或用 0 返回等轴测视图。
